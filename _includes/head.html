{%- comment -%} ======================================================================= Link previews. Everything between here and the stylesheet exists so that a PONG link dropped in Discord, Slack, Bluesky, iMessage or X unfurls into a card with a title, a sentence and a picture, instead of showing up as a bare url. Chat is how this club actually shares things, and chat clients only read the . One set of values feeds three vocabularies -- plain , Open Graph (og:), and Twitter cards -- because the crawlers disagree about which to read. Discord, Slack, Bluesky, iMessage, Facebook and LinkedIn all read Open Graph; X reads twitter: first and falls back to og:; search engines want the plain description. So the values are resolved once below and then printed three times. Resolution order for each value: this page's front matter, then something sensible derived from the page, then the site-wide default from _config.yml. Nothing here may assume front matter exists -- the tabs (home, about, events, games, posts) carry neither a title nor a description, and they get previewed too. ======================================================================= {%- endcomment -%} {%- comment -%} Title.
